Consequences observed during the run
------------------------------------
- Cold boot only: `bootmode "snapshot"` is rejected ("Hot boot is not enable"), so every restart
  re-verifies the system images (system.img alone took 347 s).
- The guest kernel-panicked twice ("sysrq triggered crash") while the host was stopping and
  restarting the HVD; the measurement boot itself stayed up for the whole run.
- All timings in probe-rows.txt are from this host. Timer/scheduling cost dominates the measured
  drain, so the absolute values are host-bound and must not be read as app behaviour on a phone.
