## Что исполняем

Мандат пользователя 2026-08-31: **production quality по актуальному iOS-референсу**. Тег `v0.1.0`
как отдельная цель отменён (см. `DECISIONS.md` D24); «день догфуда» остаётся метрикой, но не
единственной.

Порядок фаз — из `TASKS/PRODUCTION_PARITY_PLAN.md`:

1. **Надёжность** — активная фаза, но только по воспроизведённым дефектам; без измерения не чинить.
2. **Качество существующего UI** — по актуальному iOS-референсу и уместным нативным элементам.
3. **Функциональная полнота** — по одной законченной вертикали (TDLib contract → state/events →
   tests → UI states → device scenario).
4. **Публикационная готовность** — подпись, release-сборка, store-checklist.

## Обязательный preflight

исполнять их роадмапы и не поддерживать их в актуальном состоянии.

## Глобальные правила

- Каждый срез имеет критерий «готово», видимый пользователю.
- **iOS-фиделити — это цель, а не побочный эффект.** Визуальная и поведенческая точность по
  референсу обязательна; правило «пиксельная фиделити не является целью» отменено вместе с Release
  Track v2.
- Минимальные изменения. Верификация: `scripts/smoke-build.ps1` + `scripts/smoke-ui-phase0.ps1`;
  для рантайм-поведения — эмулятор или устройство.
- Мета-тулинг расширять только под реальную воспроизведённую регрессию. Измерения и их отчёты
  живут в `docs/reviews/`, харнесс — в `probe/`.
- После значимой работы обновлять `STATUS.md`, `TASKS/TODO.md`, `TASKS/LESSONS.md`.
- Commit/push — только по явной команде пользователя.

## Состояние — что закрыто, что нет

**Закрыто:** receive scheduling correction (2026-10-18); receive-drain topology и slice budget
(2026-10-21/23, `D23`); анализ ArkGram (2026-10-21, исправлен 2026-10-23).

**PARTIAL:** main reliability (request timeouts) — нужны измерения, а не правки; политика ёмкости
(4 батча / 16 MiB / 30 s) — решение пользователя.

**Открыто:** authenticated delivery и провайдеры, подпись и релиз, визуальный паритет, очередь фич и
UI-дефектов из `TASKS/TODO.md`.

## Заморожено до отдельного решения

- VoIP-звонки (страница Calls остаётся read-only списком).
- Мультиаккаунт, боты-UI, секретные чаты, админка каналов.
- `Repeat` / `@ReusableV2` perf-релиз — только после измерений.
- Полиш сверх текущего состояния галереи и поиска — по `TASKS/TODO.md`.

## Отдельные треки (требуют внешних ресурсов)

- **Push-уведомления и inline reply** — нужен AGC/Push Kit и решение по провайдеру; в
  `TASKS/TODO.md` висит как продуктовый пробел, в `AGENTS.md`/`CLAUDE.md` — как открытый гейт.
- **Подпись и release-сборка** — блокер публикации (DevEco-сертификат).
- **AppGallery** — только по явному запросу.
