## Purpose

Canonical execution roadmap. If the user says `иди по плану` / `go by the plan` / `continue roadmap` — read this file and execute the **current phase** in order.

**Product goal:** минимальный релизный Telegram-клиент (**v0.1.0**), которым можно пользоваться каждый день. После релиза фичи добавляются маленькими обновлениями: **одна фича = один цикл = один тег v0.x**. Ширина роадмапа больше не цель. Целевая метрика: «день догфуда без crash / freeze / потери сообщений».

## Global rules

- Фаза без критерия «готово», видимого пользователю, не допускается.
- Не расширять мета-тулинг (heartbeat / runtime-sweep скрипты) без реальной воспроизведённой регрессии.
- Пиксельная iOS-фиделити не является релизной целью; работающая семантика Telegram — является.
- Минимальные изменения; верификация: `scripts/smoke-build.ps1` + `scripts/smoke-ui-phase0.ps1`; для рантайм-поведения — эмулятор.
- Обновлять `STATUS.md`, `TASKS/TODO.md`, `TASKS/LESSONS.md` после значимой работы.
- Commit/push — только по явной команде пользователя.

## R0 — Консолидация и чистка

### Goal
Одно дерево, один план, чистый репозиторий.

### What to do
1. Закоммитить верифицированный throttling-патч `DownloadMessageMediaUseCase` + docs (по команде пользователя)
2. Обновить `TASKS/CURRENT_PATCHSET_BOUNDARY.md` после коммита
3. `.gitignore`: `.cpl/`, `hs_err_pid*.log` (сделано 2026-07-02)
4. Прогнать MVP-чеклист один раз на эмуляторе; каждый провал записать отдельным дефектом в `TASKS/TODO.md` (R1 backlog)

### Exit condition
Рабочее дерево чистое; MVP-чеклист превращён в конкретный дефект-список.

## R1 — MVP-стабилизация (догфуд-цикл)

### Goal
Все пункты MVP-чеклиста зелёные на эмуляторе (устройство — если появится).

### What to do
1. Чинить дефекты из чеклиста в порядке влияния на ежедневное использование
2. AppFreeze re-check: release-сборка, холодный старт, свежий faultlogger (детекция AppFreeze работает только на release-версии)
3. Unit-покрытие троттлинга `DownloadMessageMediaUseCase` (scheduleScan dedupe, budget cap + rescan chain, stop() timer cleanup)
4. Скролл чат-листа и чата: субъективно плавный на эмуляторе; профилировать только при видимых лагах

### Exit condition
MVP-чеклист полностью зелёный + день догфуда без crash / freeze / потери сообщений.

## R1.5 — Внешний вид (гейт перед релизом, добавлен 2026-07-02)

Пользовательское решение: релиз не намечается, пока внешка не устраивает.

### Goal
Основные экраны (чат-лист, экран чата, верхние табы/чром, нижний композер) выглядят так, что пользователь готов это релизить.

### What to do
1. Собрать конкретный дефект-лист внешки по экранам: текущие Telegram iOS runtime screenshots + `C:\Refs\Telegram\Telegram-iOS-current`; архивные сравнения и `Telegram-iOS-snapshot-2026-02-10` — только исторический ориентир
2. Согласовать список с пользователем (что чинить, что оставить платформенно-нативным — стратегический сплит из архива плана сохраняется)
3. Точечные правки токенов/чрома/композера без возврата к обязательному spec+demo конвейеру
4. Приёмка пользователем по скриншотам/живому прогону

### Exit condition
Пользователь подтверждает: «внешка ок для v0.1.0».

## R2 — Релизная упаковка v0.1.0

Prerequisite: R1 (MVP-чеклист) и R1.5 (внешка) закрыты.

### Goal
Подписанная release-сборка, которой пользуются ежедневно.

### What to do
1. `signingConfigs` в `build-profile.json5` (личный сертификат через DevEco)
2. Иконка, имя приложения, версия, минимальный about
3. Release-сборка + установка на устройство/эмулятор
4. Тег `v0.1.0` + короткий changelog

### Exit condition
Установленная подписанная v0.1.0; известные ограничения записаны в `STATUS.md`.

## R3+ — Фичи обновлениями

Правило: одна фича = один цикл = один тег v0.x. Кандидаты (порядок уточняется догфудом):
1. Уведомления уровня приложения (in-app / badge; системный push — отдельный трек)
2. Поиск (в чате / глобальный) — полиш
3. Галерея — полиш (зум, свайп между медиа)
4. Тёмная тема / темы
5. Профили / настройки аккаунта
6. Perf-релиз: `Repeat` / `@ReusableV2` по результатам измерений
7. AppGallery-трек (если захочется публичного релиза)
