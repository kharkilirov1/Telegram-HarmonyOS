# WITNESS — живые наблюдения на устройстве/эмуляторе

Каждая запись — что именно наблюдалось, где, когда и чем доказано. Сюда попадают только сценарии,
которые реально видели; код и суиты доказательством не считаются (`CAPABILITY_MATRIX` правило 2).

Повторить прогон: `powershell -ExecutionPolicy Bypass -File .\scripts\witness-emulator.ps1`.
Скрипт поднимает эмулятор, ждёт hdc, запускает приложение, проверяет свежий процесс, снимает кадр
через `uitest screenCap` и считает fault-логи. Скриншоты складываются в `.witness/` (в git не идут).
`snapshot_display` для кадров не используется: на headless-эмуляторе он отдаёт недорисованный кадр
с серой областью (LESSONS 273).

## 2026-11-05 — эмулятор "Mate 90 Pro", HarmonyOS 7.0.0, API 26, x86_64

Окружение: `Emulator.exe -start "Mate 90 Pro" -noWindow`; `hdc tconn 127.0.0.1:5555`;
установленный пакет `com.telegram.harmonyos` (без переустановки HAP, данные сохранены);
`const.ohos.apiversion` = 26.

| Что проверено | Как | Результат |
|---|---|---|
| Холодный старт | `aa force-stop` → `aa start -a EntryAbility -b com.telegram.harmonyos` → `ps -ef` | Процесс `com.telegram.harmonyos` жив, STIME 15:47:23 против device date 15:48:10 — процесс новый, не унаследованный |
| Fault-логи | `ls /data/log/faultlog/faultlogger \| wc -l` | 0 |
| Экран входа | `uitest screenCap` | Обезьяна-логотип, заголовок «Ваш номер телефона», подпись, строка страны (🇷🇺 Russia), поля `+7` и «Номер телефона», кнопка «Продолжить» (disabled), ссылка «Log in by QR Code» |
| Ввод номера | `uitest uiInput click` по полю | Открывается системная цифровая клавиатура, поле получает фокус, layout сдвигается (Scroll работает) |
| Выбор страны | тап по строке страны → шит «Выберите страну» | Шит рисуется: поиск, секции A/B/C/E/F/G, флаги, коды, алфавитный индекс справа; выбор Azerbaijan применился к полю (`+994`) |
| Состояние кнопки | визуально | «Продолжить» disabled при пустом номере — как в iOS |

Не покрыто этим прогоном (нужен авторизованный аккаунт): чаты, истории, уведомления, настройки,
медиа, реакции, перевод. Эти строки остаются `partial` до отдельного witness-прогона.
