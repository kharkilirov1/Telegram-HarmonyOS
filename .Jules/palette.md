## 2024-05-14 - ArkUI Accessibility Descriptions for Interactive Elements
**Learning:** In HarmonyOS ArkUI, applying accessibility modifiers to dynamic UI components or top bar capsules requires adding `.accessibilityGroup(true)` and `.accessibilityDescription()` to the interactive parent container (e.g., Row or Column). For icon-only components (like TgIcon) that need interaction, they must be wrapped in a container (like a Row), and the `onClick` handler, margins, and accessibility modifiers must be moved to the new wrapper to avoid layout regressions and redundant screen reader announcements.
**Action:** Always wrap interactive icon-only components in a container (Row/Column) and apply `.accessibilityGroup(true)`, `.accessibilityDescription()`, and `onClick` handlers directly to the wrapper. For already wrapped components (like capsules), apply accessibility modifiers directly to the root interactive container.
