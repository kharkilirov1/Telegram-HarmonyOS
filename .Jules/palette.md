## 2024-05-25 - Grouping interactive ArkUI capsule components for accessibility
**Learning:** In HarmonyOS/ArkUI, interactive containers with multiple sub-elements (like title and subtitle texts inside a chat top bar capsule) are fragmented by screen readers. Applying `onClick` directly to an icon (like a clear button) instead of a wrapper `Row` causes redundant announcements and shrinks the touch target if a new wrapper is added later without moving the handlers.
**Action:** When adding accessibility to complex interactive capsules (like `TgChatTopBar`), apply `.accessibilityGroup(true)` and `.accessibilityDescription()` directly to the interactive parent wrapper (e.g., `Row`/`Column`) rather than individual elements. If an icon-only component needs interactivity and accessibility, wrap it in a container, move the `onClick` and margins to the container, and apply the accessibility modifiers there.
