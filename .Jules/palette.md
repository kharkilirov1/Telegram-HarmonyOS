## 2024-05-24 - Interactive Component Container Accessibility and Dynamic State
**Learning:** Applying accessibility descriptions to nested icon components (e.g., `TgIcon`) within interactive wrappers (e.g., `Row`) inappropriately shrinks the interactive area. Furthermore, multi-state components (like a combined send/record voice button) must have dynamic descriptions to accurately reflect the current context to screen readers.
**Action:** Explicitly apply `.accessibilityGroup(true)` and `.accessibilityDescription()` solely on the interactive parent wrapper handling the click event, not the inner elements. Utilize a ternary operator for dynamic state buttons to accurately announce the current capability (e.g., `.accessibilityDescription(this.canSend() ? 'Send' : 'Record voice message')`).
