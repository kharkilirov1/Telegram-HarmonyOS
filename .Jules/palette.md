## 2024-05-01 - ArkUI Icon Button Accessibility Grouping\n**Learning:** When making icon-only components (like `TgIcon`) accessible in ArkUI, do not attach accessibility attributes directly to the icon if it is part of an interactive area with margins. Instead, wrap the icon in a `Row` or `Column`, move the `onClick` handler and layout properties (like `margin`) to the wrapper, and apply `.accessibilityGroup(true)` and `.accessibilityDescription()` to the wrapper. This ensures accurate hit targets and clean screen reader announcements without redundancy.\n**Action:** Always wrap custom icon components in native containers before making them interactive/accessible.
