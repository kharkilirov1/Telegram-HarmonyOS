## 2024-10-24 - Screen Reader Fragmentation in Multi-Layer Components
**Learning:** In complex multi-layered ArkUI components like top bar capsules, text and icons get read out individually if the parent interactive container isn't explicitly grouped. Also, directly applying onClick and accessibility to an atom like TgIcon inside a layout can reduce touch targets or cause redundant readouts unless wrapped in a layout node.
**Action:** Always apply .accessibilityGroup(true) to the outer interactive Row or Column to present the interactive element as a single screen-reader block, and dynamically combine state strings (like title + subtitle) into a cohesive .accessibilityDescription(). For icon-only components, wrap them in a structural node (Row/Column) before adding onClick and accessibility modifiers to preserve proper margins and hit areas.
