## 2024-05-20 - Adding Accessibility Attributes in ArkUI Components
**Learning:** Adding `.accessibilityGroup(true)` to interactive elements ensures screen readers group their contents correctly, which is critical for complex interactive views like iOS-style glass top bars in ArkUI where there's multiple layered capsules (back button, title stack, avatar). The UI shell smoke tests locally strictly enforce specific state decorators like `@Reusable` on list rows, but as a UX persona, be cautious about inadvertently modifying performance optimizations due to strict role boundaries unless it is required to pass the test suite to merge the UX improvement. The missing string resource was flagged in code review, but verifying the `string.json` shows that `$r('app.string.accessibility_back')` is in fact predefined and safe to use.
**Action:** Always verify `string.json` for existing translations before adding literal strings, and add `.accessibilityGroup(true)` along with `.accessibilityDescription()` to complex interactive groups like top bars.
