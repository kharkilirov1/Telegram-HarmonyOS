## 2024-07-07 - Accessibility for Custom Interactive Layout Containers (iOS-style capsules)
**Learning:** Screen readers struggle with custom layout containers acting as buttons unless explicitly configured. Also, for icon-only interactive components (like clear search) inside complex layouts, applying accessibility properties directly to the icon can sometimes interfere with layout or touch target sizes if not carefully scoped.
**Action:** Always apply `.accessibilityGroup(true)` and a hardcoded literal `.accessibilityDescription()` to the root container of an interactive capsule. When a raw `TgIcon` acts as a button, wrap it in a `Row` container, shift the `onClick` and layout modifiers (like margins) to the `Row`, and apply accessibility to the `Row` to maintain the desired touch target and layout integrity.
