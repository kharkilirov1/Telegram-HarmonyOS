## 2024-05-18 - Nested Accessibility Grouping in ArkUI Custom Components
**Learning:** In ArkUI, explicitly adding `.accessibilityGroup(true)` and `.accessibilityDescription()` directly to icon-only custom components (like `TgIcon`) within interactive containers is sometimes insufficient if the parent container itself lacks grouping. Screen readers might skip the children entirely if the parent is an interactive container that isn't properly grouped, or they might fragment the reading. Furthermore, adding accessibility to the child while *also* adding it to the parent wrapper (`Row`/`Column`) ensures that the interactive touch target (the parent `Row`) is properly announced by the screen reader.
**Action:** When making custom container components interactive and accessible, apply `.accessibilityGroup(true)` and `.accessibilityDescription(...)` to both the interactive wrapper (the touch target) and its direct custom children (e.g., `TgIcon`) if needed to ensure ArkUI's accessibility tree propagates the labels correctly.
