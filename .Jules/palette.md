## 2024-07-24 - Accessibility and Touch Target Expansion in TgChatTopBar
**Learning:** Icon-only interactive elements in ArkUI (like back buttons, clear search, and search mode triggers) require wrapping in layout containers (e.g., `Row`) configured with standard touch target sizes (e.g., 44x44vp using `CHAT_TOP_BAR_CAPSULE_SIZE`) to ensure optimal usability. Applying `onClick` directly to an `Image` or small `TgIcon` without a properly sized wrapper results in a reduced touch target and missing standard visual feedback.
**Action:** When making icon-only components interactive, always wrap them in appropriately sized containers, apply `.clickEffect({ level: ClickEffectLevel.LIGHT })`, and explicitly group the accessibility node with `.accessibilityGroup(true)` and a descriptive `.accessibilityDescription(...)` directly on the wrapper container.
