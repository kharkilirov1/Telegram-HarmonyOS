## 2024-07-20 - Top Bar Action Accessibility
**Learning:** In ArkUI, when making custom container components interactive and accessible, explicitly apply `.accessibilityGroup(true)` and `.accessibilityDescription()` ONLY to the interactive parent wrapper (e.g., Row/Column). If an icon-only component (like `TgIcon`) needs to be interactive, wrap it in a `Row`/`Column` with proper sizing, move the `onClick` handler and margins to the wrapper, and apply accessibility attributes there to avoid redundant screen reader announcements and prevent the touch target from shrinking.
**Action:** Always wrap interactive icon-only components in layout containers (like `Row`) to increase touch target size, apply `.clickEffect({ level: ClickEffectLevel.LIGHT })` to the wrapper, and attach accessibility attributes to the wrapper instead of the raw icon component.
